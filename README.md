# LANDING PAGE - GRAN CARRERA ROSA NOGALES 2026

Landing Page para la Tercera Gran Carrera Rosa de Nogales, organizada por Altruistamente Locos y Agrupación George Papanicolaou de Nogales, Sonora I.A.P.

Desarrollada enteramente en el framework de React + Vite, con panel de administrador bloqueado a base de credenciales, optimizada y amigable para su uso en cualquier dispositivo y base de datos desarrollada en la nube de Supabase (PostgreSQL).
